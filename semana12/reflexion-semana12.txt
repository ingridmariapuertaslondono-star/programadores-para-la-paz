Durante este curso aprendí que la tecnología puede ser una herramienta muy importante para fortalecer la participación ciudadana y la organización comunitaria. Comprendí cómo una aplicación puede ayudar a registrar información de forma organizada mediante una base de datos. También aprendí la importancia de conectar el frontend con el backend para que un sistema funcione correctamente. Conocí el uso de Git y GitHub para controlar versiones y publicar proyectos de manera segura. Además, entendí que la automatización con herramientas como n8n o Telegram permite ahorrar tiempo al enviar notificaciones automáticamente. Aprendí que la generación de documentos PDF facilita presentar información de forma profesional. También comprendí la importancia de proteger los datos personales y recopilar únicamente la información necesaria. Todo lo aprendido me permitirá desarrollar soluciones tecnológicas útiles para beneficiar a la comunidad.
